# Быстрый запуск на macOS

## Самый простой способ

1. Распакуйте архив `kodex-citation-desktop-final.zip`.
2. Откройте папку приложения.
3. Дважды нажмите файл **«Запустить Кодекс.command»**.
4. При первом запуске macOS может показать предупреждение безопасности. Если это произошло:
   - нажмите файл правой кнопкой;
   - выберите **Открыть**;
   - подтвердите запуск.

Скрипт сам проверит Node.js, установит зависимости, соберет приложение, дождется готовности сервера и откроет браузер на:

```text
http://127.0.0.1:5000/#/
```

Если Safari открыл пустое окно или в адресной строке видно только `localhost`, вставьте адрес выше вручную. Важно, чтобы в адресе были `127.0.0.1`, порт `5000` и `/#/` в конце.

## Если Node.js не установлен

Установите Node.js 20 LTS или новее:

```text
https://nodejs.org/
```

После установки снова запустите **«Запустить Кодекс.command»**.

## Как остановить приложение

Закройте окно Terminal, в котором запущен «Кодекс», или нажмите:

```text
Control + C
```

## Альтернативный запуск через Terminal

```bash
cd путь/к/папке/citation-desktop
./start-codex.sh
```
