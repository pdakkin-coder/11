# Кодекс Citation Desktop

Локальная версия академического приложения для анализа документов, цитирования и редакторских подсказок.

## Что входит

- Импорт DOCX, TXT, Markdown и HTML.
- Импорт по публичной ссылке, включая Google Docs и Google Drive links.
- Поиск внутритекстовых ссылок, сносок, Ibid./«Там же», цитат и библиографии.
- Определение APA и Chicago, а также преобразование в APA, Chicago, MLA, IEEE, Vancouver, Harvard, ГОСТ и авторский стандарт.
- Конструктор авторской нотации с шаблонами `{author}`, `{year}`, `{title}`, `{source}`, `{n}`.
- Экспорт исправленного документа в DOCX, TXT, Markdown и HTML.
- Экспериментальная кнопка Google Drive: для автономной работы нужен отдельный Google OAuth/API проект; в текущей поставке используйте локальный экспорт и загрузку в Drive вручную.

## Требования

- Node.js 20 или новее.
- npm 10 или новее.

## Быстрый запуск

### macOS — самый простой запуск

1. Распакуйте архив.
2. Дважды нажмите **«Запустить Кодекс.command»**.
3. Если macOS покажет предупреждение безопасности, нажмите файл правой кнопкой → **Открыть**.

Скрипт сам установит зависимости, соберет приложение при необходимости, дождется готовности сервера и откроет браузер на `http://127.0.0.1:5000/#/`.

### macOS / Linux через Terminal

```bash
chmod +x start-codex.sh
./start-codex.sh
```

После запуска откройте:

```text
http://127.0.0.1:5000/#/
```

### Windows

Дважды щёлкните `start-codex.cmd` или выполните:

```cmd
start-codex.cmd
```

После запуска откройте:

```text
http://127.0.0.1:5000/#/
```

## Ручной запуск

```bash
npm install
npm run build
npm start
```

## Ограничения финальной версии

- DOCX-экспорт сохраняет текст, заголовки и базовую структуру, но не восстанавливает сложные Word-сноски как настоящие структурные footnotes.
- Конвертация цитирования основана на эвристиках и требует академической проверки.
- Прямой экспорт в Google Drive из автономного приложения требует отдельной OAuth-интеграции Google Cloud; connector Perplexity недоступен как встраиваемый credential внутри standalone-приложения.
